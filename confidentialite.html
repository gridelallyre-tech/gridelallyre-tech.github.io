Politique de confidentialité

Dernière mise à jour : 19 novembre 2026

1. Données utilisées

Lors de la connexion du propriétaire à son compte TikTok, l'application reçoit uniquement :

  • les informations de base du profil (identifiant, nom affiché, avatar), via l'autorisation user.info.basic ;
  • un jeton d'accès permettant d'envoyer des vidéos sur ce compte, via l'autorisation video.upload.

2. Finalité

Ces données servent exclusivement à envoyer les clips vidéo sur le compte TikTok du propriétaire. Elles ne sont utilisées à aucune autre fin : pas de publicité, pas de statistiques, pas de profilage.

3. Stockage

Le jeton d'accès est enregistré localement, sur l'ordinateur du propriétaire uniquement. Aucune donnée n'est envoyée sur un serveur tiers, vendue ou partagée.

4. Données de tiers

L'application ne collecte aucune donnée personnelle des spectateurs Twitch ou TikTok. Le nombre de messages du chat Twitch public est seulement compté, en direct, pour repérer les moments forts. Aucun message ni pseudo n'est enregistré.

5. Durée de conservation et suppression

Le jeton est conservé tant que l'application est utilisée. Il peut être supprimé à tout moment en effaçant le fichier local ou en retirant l'accès de l'application dans les paramètres du compte TikTok (Paramètres et confidentialité → Sécurité → Applications autorisées).

6. Contact

Pour toute question sur cette politique, contacte le propriétaire via la messagerie de son compte TikTok.
